# Design lab

A single self-contained page for iterating the qader.dev revamp without
rebuilding HTML and CSS each time. Open `index.html` directly in a browser --
no server, no build step.

The panel on the right switches structure, palette, instrument placement,
transition, colormap, caption and measure live. Keyboard: `p` cycles the
palette, `h` hides the panel.

`assets/depth.png` is a 600-frame depth sprite sheet (25x24 grid of 80x80
tiles, 32 levels), generated by `tools/build_depth_assets.py` from
`results_00.h5`. The frame metadata and the provisional motif sequence are
inlined in `index.html` so the page has no fetches and works from `file://`.

This is a prototype, not the site. The site is built from whatever this
settles on; see `../2026-11-04-site-revamp.md`.
